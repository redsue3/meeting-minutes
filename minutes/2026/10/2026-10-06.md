### 22:27–22:46 · Windows 11 Pro 정품 인증 재요구 원인 점검

프로젝트 `홈 폴더` · 세션 `4cfcc568` · `Windows 11` `정품 인증` `KMS` `slmgr` `라이선스 오류`

사용자가 이미 인증했는데 Windows 정품 인증 요구가 계속 뜬다고 문의했고, Claude가 인증 상태를 조회해 KMS 범용 키로 인증된 알림 모드임을 확인했다. 정품 키로 교체하는 절차를 안내했으나 Claude 세션에 관리자 권한이 없어 키 설치는 실행하지 못했다. 사용자가 직접 키를 입력했을 때 '제품 키가 잘못되었다'는 오류가 나와 원인 후보를 안내한 상태로 끝났다.

**안건**

- Windows 정품 인증이 반복해서 요구되는 원인 파악
- 정품 키로 교체하는 방법
- 제품 키 설치 시 잘못된 키 오류 원인 분석

**논의 내용**

- KMS 인증은 180일마다 갱신이 필요해서, 갱신이 안 되면 인증이 풀려 알림 모드가 된다는 설명이 나왔다.
- KMS 클라이언트 인증이 회사나 학교 서버 때문인지, 인터넷 인증 툴 때문인지에 따라 대응이 달라진다고 Claude가 구분했고 후자의 재인증은 돕지 않겠다고 밝혔다.
- '제품 키가 잘못되었다' 오류의 후보로 글자 오입력, Home용 등 에디션 불일치, Enterprise·Education 키는 changepk로 에디션 변경 가능성이 제시되었다.
- 설정 화면의 제품 키 변경에서 시도하면 에디션 불일치 시 더 자세한 안내가 나올 수 있다는 의견이 있었다.

**결정 사항**

- 기존 KMS 키와 설정을 제거한 뒤 사용자가 가진 정품 키를 설치하는 방향으로 진행하기로 했다.
- 키 입력과 인증은 관리자 권한이 필요하므로 사용자가 관리자 터미널에서 직접 실행하기로 했다.

**진행한 작업**

- Windows 인증 상태를 조회해 Windows 11 Pro가 KMS 클라이언트 키로 알림 모드(유예 0일)임을 확인했다.
- 정품 키 교체 절차를 설정 화면 방식과 명령어 방식 두 가지로 안내했다.
- 키 설치를 시도했으나 관리자 권한 부족으로 거부되어, 현재 세션이 관리자 권한이 아님을 확인했다.
