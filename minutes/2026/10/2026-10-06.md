**결정 사항**

- 기존 KMS 키와 설정을 제거한 뒤 사용자가 가진 정품 키를 설치하는 방향으로 진행하기로 했다.
- 키 입력과 인증은 관리자 권한이 필요하므로 사용자가 관리자 터미널에서 직접 실행하기로 했다.

**진행한 작업**

- Windows 인증 상태를 조회해 Windows 11 Pro가 KMS 클라이언트 키로 알림 모드(유예 0일)임을 확인했다.
- 정품 키 교체 절차를 설정 화면 방식과 명령어 방식 두 가지로 안내했다.
- 키 설치를 시도했으나 관리자 권한 부족으로 거부되어, 현재 세션이 관리자 권한이 아님을 확인했다.

**후속 작업**

- [ ] 사용자: 관리자 터미널에서 기존 키 제거, 레지스트리 키·KMS 설정 삭제, 정품 키 설치, 인증 순서로 실행해 본다.
- [ ] 사용자: 구매 내역에서 키의 에디션(Home 또는 Pro)과 판매처를 확인하고, 헷갈리기 쉬운 글자를 다시 대조한다.
- [ ] 사용자: 설정의 제품 키 변경 화면에서 키를 넣어 보고 나오는 정확한 오류 코드를 Claude에게 알린다.
- [ ] 사용자: 정상 구매한 키인데도 계속 거부되면 판매처나 Microsoft 지원에 문의한다.

**이슈·리스크**

- 정품 키를 설치할 때 '제품 키가 잘못되었다'는 오류가 계속 나며 원인이 아직 특정되지 않았다.
- 정확한 오류 코드와 키의 에디션을 알 수 없어 Home용 키인지, 오입력인지, 차단된 키인지 확정하지 못했다.
- 대화에 제품 키 전체가 노출되었으므로 공유 시 주의가 필요하다.
- 이전에 어떤 방식으로 KMS 인증을 했는지 확인되지 않았고, 인증 툴이 만든 예약 작업이나 서비스가 남아 있을 가능성이 있다.
