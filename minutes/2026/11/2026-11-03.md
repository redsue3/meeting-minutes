- 현재 훅은 API 호출과 규칙만 쓰므로 토큰 없이 돌지만, 마감 목록 모음만으로는 혁신성과 AI 요소가 부족해 지각 위험 예측을 중심에 두기로 했다.

- 모델은 데이터가 수백 건 수준이고 이유 설명이 쉬운 로지스틱 회귀로 하고, 초기에는 손으로 가중치를 준 규칙 점수를 쓰다가 AUC로 비교해 나은 쪽을 쓰기로 했다.

- 커뮤니티 크롤러 웹 UI 실행

**논의 내용**

- 사용자가 코딩테스트·인적성 준비, 직무·포트폴리오 준비, 면접 대비, AI 처리 절차 등 영상의 실제 내용을 알려 주어 이를 과제 1의 1·2번과 과제 2에 반영하기로 했다.
- PC의 로컬 pain-miner 폴더는 9월 파이썬 버전이고 GitHub는 더 최신 Node 버전이라, 기존 폴더는 두고 최신 코드를 별도 폴더에 받아 실행하는 쪽을 택했다.

### 22:17–23:46 · 벽 방음재 견적·가벽 재단표·흡음재 비교

프로젝트 `scratch-2026-11-03-640bc3` · 세션 `5cd28203` · `방음재` `차음재` `흡음재` `쿠팡 가격비교` `가벽 재단표` `DIY 인테리어`

사용자가 403×228cm 벽에 5T 이상 방음재를 붙이려고 Claude에게 쿠팡 기준 견적을 요청했다. 커뮤니티 댓글을 검토한 뒤 프레임+석고보드 가벽 견적과 재단표를 만들었고, 이후 협찬 리뷰를 거른 부착식 차음재·흡음재 비교 대시보드와 조합표를 만들었다. 일부 제품은 쿠팡의 리뷰 조회 차단으로 협찬 리뷰를 거르지 못했고 페이지 자동 점검도 끝나지 않았다.

**안건**

- 403×228cm 벽(9.19㎡)에 붙일 차음·흡음재 견적
- 커뮤니티 댓글 조언 검토와 소음 감소 효과 수치화
- 프레임+석고보드 가벽 견적 및 재단표 작성
- 석고보드 제외, 5T 이상 부착식 차음재 후보 비교(협찬·포인트 리뷰 제외)
- 차음재와 함께 붙일 흡음재 조사 및 조합별 가격·수량 표

**논의 내용**

- 처음에는 EVA 5T 차음재(약 19.5만 원), 고무 차음재 5T 조합(약 22만 원), 일체형 14T 보드(약 28.7만 원)를 비교해 고무 차음재 조합을 추천했다.
- 커뮤니티 댓글은 차음의 핵심이 무게·공기층·기존 벽과의 분리라고 봤고, Claude는 붙이는 방식은 체감 소음 감소가 20~30% 수준이며 독립 프레임 가벽은 약 50~65%라고 추정했다.
- 가벽 자재비는 각재, 방화 석고보드 2겹, 흡음충진재, 부자재를 합쳐 약 40만 원에 화물 운임이 따로 붙는다고 계산했다.
- 리뷰를 확인해 보니 처음 추천한 고무 차음재 5T 두 제품은 가벼운 발포 스펀지여서 차음 효과를 기대하기 어렵다고 Claude가 정정했다.
- 실제로 무게가 있는 제품은 나라벨트 고무판 5T뿐이며 약 60~70kg이라 본드와 피스 고정이 필요하다고 봤다.
- 고무판(196,900원) 위에 붙일 흡음재 조합 중 대형 계란판 50T 난연이 성능 1위(합계 332,060원), 방염 폴리에스터 25T가 가장 싼 방염(합계 296,900원)이었다.
- 올폼 계란판, 탑형 흡음폼, 난연 표기 없는 두꺼운 폼은 잔여물·탈락·화재 우려로 피하라고 권했다.
- 성능 점수는 측정값이 아니라 소재 특성에 매긴 점수와 거른 리뷰 별점을 합친 추정치다.

**결정 사항**

- 후보 비교에서 협찬·포인트 리뷰는 제외하기로 했다.
